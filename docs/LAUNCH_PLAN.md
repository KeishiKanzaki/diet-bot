# AI栄養士ユキ：承認済みの方針とロードマップ

2026-10-20更新。以前の機能拡張案を置き換える。価格・人数・期間は検証用の仮説。

## コンセプト

「食事の写真をLINEで送るだけ。カロリーの目安と、ちょっとした工夫、温かい励ましが届く。」
ユキとやり取りする気軽さを価値にする。減量成果や写真の数値の正確性は保証しない。
AIであり、人の管理栄養士・医師ではない。監修者はいない。

## 最初の顧客

18歳以上の一般成人。仕事が忙しく、外食・コンビニ食が多く、食事入力アプリが続かなかった人。
食生活は気になるが、厳しい指導や細かな管理は負担という人を最初の仮説にする。
例は32歳の会社員。年齢・性別で需要を断定せず、実際の利用理由と離脱理由で絞る。
疾患の治療、未成年の減量、急激な減量を目的とするサービスにはしない。

## プロダクトの範囲

写真1枚に対して、料理名と推定カロリー、料理に合う工夫1つ、励ましを短く返信する。
アドバイスと励ましは同じAI解析で取得し、追加のAI呼出しをしない。
通常の案内や写真返信にはPFC、当日合計、履歴、訂正、週報、手入力の一覧を出さない。
既存の補助コマンドは互換性のため残す。既存データは削除しない。
同意、削除、アクセス制御、重複抑止、利用上限は裏側で維持する。
体重入力、目標設定、通知、ポイント、ランキング、専用アプリは追加しない。

## 実行順序

| 段階 | 実施すること | 次に進む判断 |
| --- | --- | --- |
| 1：核となる体験 | 写真返信と使い方を簡潔にし、応答例を人が確認 | 料理に合う工夫が1つ、責めない励まし、推定の明示。実LINEでも確認 |
| 2：少人数で検証 | 招待準備を整え、まず5人・7日間で試す | 写真を送りやすいか、返信が役立つか、また使いたいかを聞く |
| 3：継続と有料意向 | 続いた理由と離脱理由を確認。月額480円の仮説を提示 | 実際の継続利用と支払意向の両方を確認。未達なら返信体験を改善 |
| 4：収益化の判断 | 無料体験から同じ写真体験の有料継続を検討 | 原価・利用枠・運営者情報・公開文面・解約方法を確定してから別途実装 |

日数だけで自動的に次の段階へ進めない。利用者への連絡・招待・公開募集はまだ実行しない。
運営者名・問い合わせ先は未決定のため公開版ポリシーは保留。募集開始前に整える。

## 収益化と0円制約

月額480円は需要確認用の仮説であり、販売開始や契約の承認ではない。
機能を増やして有料化せず、ユキの写真返信を続けたいかで判断する。
API、LINE、サーバー、DB、決済手数料、返金、対応時間を含めて成立性を確認する。
売上480円がそのまま利益にはならない。無料枠が拡大後も足りるとは仮定しない。

初期費用・運用費0円を優先する。有料API、有料プラン、カード登録、広告、決済契約を勝手に有効化しない。
無料枠に近づいたら招待人数や利用回数を絞り、必要なら停止する。有料への自動切替は実装しない。
費用が必要になった時点で金額と条件を示し、明示承認があるまで実行しない。
